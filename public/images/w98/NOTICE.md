# Windows 98 application icons

https://github.com/1j01/jspaint

Pinned commit: `53be67ab8c47cc0d2168899e7481bc04839c4c81`

License: MIT. The full license is available at
`../../vendor/jspaint/LICENSE.txt`.

The Minesweeper bitmap icons come from AlexAegis/minesweeper:

https://github.com/AlexAegis/minesweeper

Pinned commit: `a240863dce2d926135162c7a97e63d949604b4a9`

License: MIT. Copyright Győri Sándor.

The source project describes these icons as original pixel art recreated with
the classic Windows game as a visual reference.

The Winamp bitmap icons are rasterized and resized derivatives of
`Winamp-logo.svg` from Wikimedia Commons:

https://commons.wikimedia.org/wiki/File:Winamp-logo.svg

Source description revision:

https://commons.wikimedia.org/w/index.php?title=File:Winamp-logo.svg&oldid=1213578579

Original SVG:

https://upload.wikimedia.org/wikipedia/commons/0/0d/Winamp-logo.svg

Source revision SHA-1: `4cae2c7a744a748df90b815737d4010909a8e5fd`.
Original raster author: Emrrans. Vector author: Pduive23. The 16×16 and 32×32
PNG derivatives were rendered with Sharp on 27 July 2026.
