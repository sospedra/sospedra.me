## First production task

- [ ] Work on exactly one full desktop floor master.
- [ ] Prefer Floor 1: Uses + Papers + stairs right.
- [ ] Create the canonical camera/scale/crop guide before generation.
- [ ] Include rear bays, open lobby, H-beams, utilities, causal lighting,
      stairs/aperture/landing, floor bands, and crop-safe corridors in the
      generated design.
- [ ] Preserve approved stall identity and structure.
- [ ] Surface the real PNG immediately as **UNVERIFIED**.
- [ ] Run the mechanical gate without trying to rescue a failed source.
- [ ] Complete semantic review.
- [ ] Stop for explicit user approval.

## Only after a floor master is approved

- [ ] Preserve its composition, palette relationships, light relationships,
      scale, and seams.
- [ ] Re-author an empty tileable wall/floor.
- [ ] Re-author or reuse the matching stair section.
- [ ] Produce each stall as a clean layerable asset without environmental
      wall/floor.
- [ ] Preserve internal stall props.
- [ ] Produce independent environmental seam props.
- [ ] Reconstruct responsive desktop/mobile layouts.
- [ ] Validate in Chrome.
- [ ] Build animation only after the static composition is accepted.

## Never do

- [ ] Never call a machine PASS “approved.”
- [ ] Never darken/tint a generic background and call it integration.
- [ ] Never ship a fixed master bitmap as the responsive floor.
- [ ] Never regenerate from a downscaled crop.
- [ ] Never rescale characters to force proportions.
- [ ] Never redesign approved stalls in the name of consistency.
- [ ] Never touch street level.
