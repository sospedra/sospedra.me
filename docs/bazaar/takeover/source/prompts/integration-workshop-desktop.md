# Workshop desktop integration Gospel — Manual + Console + Talks

Status: normative, rejection-driven production prompt for the first Bazaar 3
underground integration proof.

Read `../ART_DIRECTION.md` and `../INTEGRATION_BIBLE.md` completely before using
this prompt. If an older asset, prompt, proof, or runtime path disagrees with
this file, this file and the latest explicit user instruction win.

This floor is the calibration floor for Bazaar 3. It must prove that three
radically different approved stalls can inhabit one physical underground
building without becoming matching storefronts. A technically valid but
visually pasted-on result is a failure.

---

## 0. Declare the output mode before generating

Every generation must declare exactly one of these modes. The two modes have
different acceptance rules and must never be confused.

### Mode A — design proof

Generate one wide composite used only to judge composition, interleaving,
lighting, and physical integration.

- The proof may show the approved stall references and the real stair sprite as
  separate, unchanged composited layers.
- The proof may be opaque.
- The proof must show the intended final layer order.
- The proof is not a production asset.
- Never copy a proof PNG into the runtime asset directory.
- Never crop a usable runtime layer out of a proof.
- Never treat an attractive proof as evidence that runtime registration works.

### Mode B — runtime layer

Generate exactly one named production plate for one declared layer phase.

- Canvas is exactly `1248 × 597`.
- Logical authored grid is exactly `416 × 199`.
- Enlarge exactly 3× with nearest-neighbour scaling.
- Every authored pixel becomes one uniform `3 × 3` output block.
- Use the deterministic registration guide supplied as Image 1.
- Preserve the guide coordinate system exactly.
- Do not translate, crop, rescale, rotate, mirror, stretch, or reframe.
- Include only the content assigned to the requested layer.
- Do not bake any stall, keeper, sign, character, stair sprite, dialog,
  hitbox, or unrelated phase into the plate.
- Areas not assigned to the requested layer must remain fully transparent, or
  perfectly flat `#ff00ff` when a keyed source is explicitly requested.
- A runtime layer that contains a rectangular copy of an opaque design master
  is automatically rejected.

If the request does not identify Mode A or Mode B, stop. Do not guess.

## 5. Shared building architecture

The floor is a reclaimed section of an older industrial service building. Its
structure is heavy, repaired, asymmetric, and load-bearing. It is not a clean
commercial fit-out.

### Required large forms

Build these as connected parts of one system:

1. **Rear wall mass**
   - Broad near-black repaired concrete and steel planes.
   - Large quiet value groups, not noisy texture.
   - A few protected rectangles, patched anchor scars, and old service seams.
   - The wall remains readable when all stalls are mentally removed.

2. **Continuous overhead H-beam**
   - One heavy, non-repeating structural run, approximately `y 48–84`.
   - Clearly drawn H/I-beam anatomy: outer flange, recessed web, lower flange,
     end plates, and a few purposeful bolts.
   - It carries visual weight and ties into the left stair receiver.
   - It may be repaired or spliced, but it may not become three repeated booth
     roofs.

3. **Two mandatory H-beam separators**
   - One occupies the real Manual–Console gap.
   - One occupies the real Console–Talks gap.
   - Each descends from the overhead system to a believable base plate or
     floor/fascia connection.
   - Their structural anatomy must remain legible at final displayed size.
   - They belong to the same building, but are not identical stamps: one may
     carry a splice plate; the other may carry an old conduit saddle or a
     repaired foot.
   - Split rear stem, mid flange, and foreground foot across layers when needed
     so a stall edge can pass behind one part and in front of another.
   - Never cover a face, character gesture, sign, or identity prop.
   - Never turn each stall into a complete H-beam cage.

4. **Shared utility rail**
   - A continuous old power/tool rail approximately `y 104–134`.
   - It must pass behind tenant structures and reappear in gaps.
   - It must have specific junctions, clamps, and branch points, not a repeated
     decorative stripe.

5. **Shared ventilation/service line**
   - A restrained line approximately `y 146–178`.
   - It bends around real structure, disappears behind stalls, and returns.
   - It must not become a giant pipe pasted across every silhouette.

6. **Real wall-to-floor transition**
   - The wall does not simply end behind the stall sprites.
   - Use a broken curb, shallow base channel, old drain lip, and protected
     rectangles where former equipment stood.

7. **Shallow floor plane**
   - The visible floor begins behind/under the stall contacts and continues to
     the front fascia.
   - Its top bands use the exact shallow Uses countertop angle.
   - It is broad, graphic, and readable, not a steep isometric diamond.

8. **Continuous grated cable trench**
   - Approximately `y 548–576`, adjusted only by the deterministic guide.
   - It must continue across the floor and visibly accept tenant cables.
   - Breaks occur only at structural feet, access plates, or real repairs.

9. **Foreground threshold/fascia**
   - Approximately `y 574–596`.
   - It gives the floor thickness and a hard front edge.
   - It may contain a few bolts, chipped paint blocks, and service cut-outs.
   - Do not fill it with evenly repeated panels or random texture.

### Architecture quality gate

With all stalls, contacts, lights, and tenant cables removed, the remaining
building must still be a coherent, drawable construction:

- overhead beam bears on separators and edge plates;
- separators meet base plates;
- utility lines respect supports;
- wall meets curb;
- floor meets trench;
- trench meets fascia;
- the left edge is ready to receive the live stair.

If any piece floats or ends arbitrarily, reject the architecture before adding
detail.

## 7. Mandatory physical interleaving

Each tenant must pass all five tests below. A single cable pasted in front is
not enough.

1. **Rear relationship**
   - At least one wall, bracket, rail, recess, or utility clearly sits behind
     the stall.

2. **Boundary crossing**
   - At least one tenant-specific utility disappears behind the stall and
     returns beside or in front of it at a logical connection.

3. **Exact support contact**
   - Contact shadows follow separate actual feet, wheels, crate edges, counter
     supports, rug pressure areas, and plinths.
   - No generic oval, trapezoid, or full-width shadow pad.

4. **Light receiver**
   - One existing practical source affects both tenant-adjacent structure and
     shared floor with hard, palette-limited receiver blocks.
   - No whole-stall tint, aura, or glow cloud.

5. **Foreground occlusion**
   - One sparse floor lip, cable, base plate, curb, railing fragment, or wear
     edge sits in front of a minor lower stall area.
   - It may overlap only expendable lower-edge pixels.
   - It must never cover identity, interaction, sign, face, character, hand,
     tool, screen, important prop, or animation envelope.

With the stall hidden, the environment must still reveal who occupied that
zone:

- ordered brackets and routed maintenance power for Manual;
- messy power, heat, cable wear, and rug protection for Console;
- coax, caster wear, tape dust, and a cool recessed media bay for Talks.

## 9. Rendering law — Uses/Games are Gospel

The result must look deliberately simplified, graphic, and authored at low
resolution. It must not look like a detailed illustration that was pixelated
afterward.

### Shape hierarchy

Build in this order:

1. silhouette and occupied/empty space;
2. large structural color masses;
3. connected shadow family;
4. one restrained highlight/wear family;
5. only then bolts, joints, labels, cables, and grime required to explain
   construction.

At thumbnail size, large forms must survive before any small prop is inspected.

### Pixel structure

- Author at `416 × 199`.
- Enlarge exactly 3× nearest-neighbour to `1248 × 597`.
- No feature finer than one authored pixel.
- No 1 px or 2 px final-resolution detail.
- Curves use deliberate stepped clusters.
- Diagonals use controlled stair-step rhythm.
- No antialiasing or fractional-alpha edge fringe.
- Do not paint high-resolution detail and apply a pixel filter.

### Material treatment

- Large uninterrupted flat-color fields dominate.
- Use normally two hard tones per material: body and connected shadow.
- Use a third tone only for a controlled edge, receiver, or important wear.
- Aim for `60–75%` base color, `20–30%` connected shadow, and `5–10%`
  highlight/wear within each major material family.
- External silhouettes and structural separations use strong near-black
  outlines.
- Interior outlines are fewer and lighter than the silhouette.
- Rust is grouped at joints, bolts, water paths, damaged feet, and old
  fasteners.
- Concrete wear is causal and sparse.
- Cables are simple readable bands with clear routes, not tangled noodle
  microdetail.
- Grates, vents, and tapes use grouped repeated shapes, not hundreds of tiny
  marks.
- Dither is rare and only used for a deep shadow transition.

### Shared-floor palette budget

Keep the building restrained enough to unite the tenants without repainting
them:

- roughly `12–16` meaningful non-emissive colors for the shared architecture;
- hard maximum about `20` meaningful non-emissive colors across all shared
  floor layers;
- one connected near-black/cold-steel value family;
- one limited rust/brass/cardboard accent family;
- one small worn-concrete family;
- tenant emissions remain separate and sparse.

Suggested near-black/cold-steel anchors:

- `#010204`
- `#05070a`
- `#090d12`
- `#0d1012`
- `#111821`
- `#181c24`

Suggested restrained warm structural accents:

- `#332214`
- `#573318`
- `#60402d`
- `#814f22`
- `#8a5130`
- `#aa7e45`

These are anchors, not a requirement to use every swatch. Fewer colors are
better when the structure remains readable.

Reject:

- painterly modeling;
- glossy 3D materials;
- smooth gradients;
- airbrushed shadow;
- bloom;
- fuzzy edges;
- random high-frequency texture;
- scratches on every surface;
- dozens of nearly identical browns or blues;
- tiny unreadable machinery;
- melted cables;
- AI pseudo-lettering;
- equal detail density everywhere.

## 10. Lighting contract

### Shared ambient

- Broad wall and floor planes remain readable.
- Deep recesses approach near-black but do not swallow silhouettes.

- **Console:** low muted-teal visor/screen blocks plus, if present, one small

Each practical must have:

- a clear source;
- a compact hard caster;
- one- or two-band receiver light;
- a visible consequence on both tenant-adjacent structure and shared floor;
- no blur or soft halo.

Do not invent additional colored lights merely to make the floor more
cyberpunk. Do not tint an entire stall to claim integration.

- A stair, stair hole, spiral, column, or duplicate landing is baked into a
  runtime plate.
- The proof stair remains visually detached from the building.

### Integration failure

- Integration is only a darker background.
- Integration is only separators.
- Integration is only a floor shadow.
- A tenant has no rear relationship.
- A tenant has no boundary-crossing utility.
- A tenant has no support-specific contact.

- A tenant has no restrained foreground overlap.

- Whole-stall halo or tint.
- Utilities end without fittings or destinations.
- Foreground art covers interaction-critical content.

### Rendering failure

- Smooth gradient, blur, bloom, antialiasing, fuzzy edge, glossy 3D, or soft
  painterly light.
- High-resolution illustration downsampled or filtered to imitate pixels.
- Any detail finer than the authored grid.
- Excess colors or many nearly identical tones.
- AI microtexture, random scratches, noisy concrete, tiny unreadable machines,
  melted cables, impossible brackets, or pseudo-text.
- Weak gray outlines instead of a deliberate near-black hierarchy.
- Deep isometric floor or tabletop.
- Rotated room, converging perspective, or nonvertical verticals.
- Random fog, motes, steam, rain, or atmospheric particles used to fill space.

### Scope failure

- Any street-level content.
- Any audio-related visual or control.
- Any dialog, navigation sign, hitbox, hover label, or UI baked into art.
- Any silent replacement of an approved source.
- Any runtime use of an opaque design-proof rectangle.

## 15. Final squint test

At roughly 300 pixels wide, the image must still immediately read as:

1. one heavy old maintenance/media building;
2. one continuous overhead H-beam;
3. two structural H-beam separators;
4. one shared rear utility system;

regardless of polish, palette, technical validity, or generation cost.
