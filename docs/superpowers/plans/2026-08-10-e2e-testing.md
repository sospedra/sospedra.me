# e2e testing implementation plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build the Playwright e2e package from the approved spec: smoke pack over every apps/main route, eleven interaction specs, sibling app smoke.

**Architecture:** One workspace package `packages/e2e` holds two Playwright configs (main + siblings), shared fixtures, and all specs. Fixtures block external hosts, track console and request health, and provide touch-swipe and canvas-painted helpers. The dev server is the webServer.

**Tech Stack:** @playwright/test (Chromium only), node 24, pnpm workspace, turbo, biome.

**Spec:** `docs/superpowers/specs/2026-08-10-e2e-testing-design.md`

## Global Constraints

- Any `pnpm-lock.yaml` change breaks vouch: run `pnpm --dir apps/vouch program-id` then `pnpm --dir apps/vouch vectors`, then `pnpm --dir apps/vouch test`.
- Never stage files from sibling sessions. `git add` explicit paths only.
- Commit subjects only. No bodies. No trailers. Convention: `type(scope): lowercase subject`.
- Do not commit a `packageManager` stamp rewrite in root `package.json` (pnpm binary drift trap).
- Assertions are structural, never content-of-the-day.
- Selectors: resolve against the named source files at execution time. Prefer role and text selectors. The assertion lists below are the contract; the skeleton selectors are the starting point.
- Ports: main 3000, bonfire 3010, wkc 5173, spg 5174.
- Playwright reports and results are git-ignored inside `packages/e2e`.

- [ ] **Step 2: Write `fixtures.ts`**

```ts
import { type Locator, type Page, test as base, expect } from '@playwright/test'

type PageHealth = {
  consoleErrors: string[]
  pageErrors: string[]
  failedSameOrigin: string[]
}

type Fixtures = { allowedHosts: string[]; health: PageHealth }

const LOCAL = new Set(['localhost', '127.0.0.1'])

export const test = base.extend<Fixtures>({
  allowedHosts: [[], { option: true }],
  health: [
    async ({ page, allowedHosts, baseURL }, use) => {
      const allowed = new Set([...LOCAL, ...allowedHosts])
      const health: PageHealth = { consoleErrors: [], pageErrors: [], failedSameOrigin: [] }
      await page.route('**/*', (route) => {
        const host = new URL(route.request().url()).hostname
        if (allowed.has(host)) return route.continue()
        return route.abort()
      })
      page.on('console', (message) => {
        if (message.type() !== 'error') return
        const source = message.location().url
        const external = source !== '' && !allowed.has(new URL(source).hostname)
        if (external) return
        health.consoleErrors.push(message.text())
      })
      page.on('pageerror', (error) => health.pageErrors.push(String(error)))
      page.on('response', (response) => {
        const host = new URL(response.url()).hostname
        if (LOCAL.has(host) && response.status() >= 400) health.failedSameOrigin.push(`${response.status()} ${response.url()}`)
      })
      await use(health)
    },
    { auto: true },
  ],
})

export { expect }

export function expectClean(health: PageHealth): void {
  expect(health.pageErrors).toEqual([])
  expect(health.consoleErrors).toEqual([])
  expect(health.failedSameOrigin).toEqual([])
}

export async function expectCanvasPainted(canvas: Locator): Promise<void> {
  const box = await canvas.boundingBox()
  if (!box) throw new Error('canvas has no box')
  const shot = await canvas.screenshot()
  // flat canvases compress to a fraction of this; painted scenes exceed it
  expect(shot.byteLength).toBeGreaterThan((box.width * box.height) / 100)
}

export async function touchSwipe(page: Page, from: { x: number; y: number }, to: { x: number; y: number }): Promise<void> {
  const cdp = await page.context().newCDPSession(page)
  const steps = 8
  await cdp.send('Input.dispatchTouchEvent', { type: 'touchStart', touchPoints: [from] })
  for (let index = 1; index <= steps; index += 1) {
    const x = from.x + ((to.x - from.x) * index) / steps
    const y = from.y + ((to.y - from.y) * index) / steps
    await cdp.send('Input.dispatchTouchEvent', { type: 'touchMove', touchPoints: [{ x, y }] })
  }
  await cdp.send('Input.dispatchTouchEvent', { type: 'touchEnd', touchPoints: [] })
  await cdp.detach()
}
```

Calibrate the exemption at execution: blocked-resource console errors must not fail specs, real app errors must.
