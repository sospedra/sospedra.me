# wkc

Which keys map to what keyboard code?

Port of [which-key-code](https://github.com/sospedra/which-key-code). Same app, modern stack: Vite 8, Tailwind 4, TypeScript 5, Biome.

- `pnpm dev` starts the dev server.
- `/` shows the pressed key as `event.which`, `event.key`, and `event.code`. A click copies the value.
- `/codes` shows the raw keyCode table.
